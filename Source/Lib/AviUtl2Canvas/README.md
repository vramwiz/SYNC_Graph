本プロジェクトでは SYNC_Graph_Filter / グラフへ変更済み。現在のビルド・配置・実機確認結果はルート README.md を参照。以下はコピー元キットの説明・履歴であり、旧名称・旧配置先・過去の確認状況を含む。

# AviUtl2 背景キャンバスキット

- ID: `aviutl2-canvas`
- 版: `1.0.0`（2026-09-28）
- 種別: キット
- タグ: AviUtl2、SYNC、フィルタープラグイン、GPU背景取得、画像バッファ、VCL、パン、ズーム
- 出典: `D:\DelphiProg\test\MapRaku` の同日時点のローカルファイル。元プロジェクトは変更しない。
- 環境: Delphi 37 / Win64、VCL、Windows D3D11。外部DLL・Skia・Google APIは不要。

## 含まれる機能

フィルター名は **キャンバステスト**、分類は **SYNC**。
設定項目は「設定」ボタンと「設定データ」の文字列パラメータのみ。
映像コールバックで合成済み背景をバッファへ保存し、設定ボタンで開く編集フォームへスナップショットとして渡す。
キャンバスには背景と外枠を表示し、左または中央ボタンのドラッグでパン、ホイールでマウスポインターを中心に拡大・縮小する。
`Fit` は画像全体を表示領域へ収める。倍率は1～3200%。

フォームを閉じるとズーム・パン位置・確認用入力欄の文字列をJSONで「設定データ」へ保存する。
画像そのものは保存しない。フィルターはホストの映像を書き換えず、編集画面の操作も出力映像には反映しない。
画像未取得の場合はその旨を表示する。取得のためにAviUtl2で対象フレームを評価してから設定を開く。
開いている間の背景の連続更新は行わず、再度開いた際に最新の取得済み画像を使用する。

## 構成とコピー対象

利用側がこのキットをコピーして組み込む。元のMapRakuやこの保管庫への絶対パス参照は不要。

| 場所 | 責務・出典 |
| --- | --- |
| `Host/AviUtl2FilterTypes.pas` | MapRakuからコピーした最小ABI宣言 |
| `Host/PluginFilterTable.pas` | MapRakuからコピーした項目登録ヘルパー |
| `Host/PluginFilterContextManager.pas` | MapRakuからコピーしたオブジェクト・効果別の状態管理 |
| `Host/SyncFrameCapture.pas` | MapRakuFrameCaptureをコピー・改名。半精度アルファのNaN処理を補正 |
| `Host/SyncCanvasPlugin.pas` | 設定ボタン、画像取得、ホストへの設定保存を最小化した接続処理 |
| `UI/SyncCanvasView.pas` | RGBA画像表示、パン、ズーム |
| `UI/SyncCanvasEditor.pas` | 最小編集フォームと版付きJSON保存・復元 |
| 保管庫ルートの `SYNC_CanvasTest_Filter.dpr/.dproj` | MapRakuのプラグインプロジェクトをコピーし、依存・名称・出力設定を整理 |

プラグイン一式を利用する場合は、保管庫ルートの `SYNC_CanvasTest_Filter.dpr/.dproj` と `Source/Lib/AviUtl2Canvas/Host`、`Source/Lib/AviUtl2Canvas/UI`、`Source/Lib/AviUtl2Canvas/Tools/build.ps1` を相対位置を維持してコピーする。
`Win64` やIDEの `.local` はコピーしない。
利用側ではプロジェクト名・GUID・フィルター表示名・データ項目名・配置先を自分のアプリ用に変更する。
VCLフォームはコードで構築するためDFMはない。

## ホスト境界とバッファの条件

- SDK型宣言はコピー元の最小定義を使用。完全なSDKではなく、SDK版番号は元ファイルに記載なし。実ホスト互換性は下記の未確認項目を参照。
- ホスト所有のテクスチャは映像コールバック内だけで使用する。D3D11 staging textureへコピーし、Mapで得たRowPitchを考慮して所有配列へ各行をコピー、Unmapする。
- GPU資源を再利用し、映像コールバック中は元形式の画素を保持する。設定画面を開くときにRGBA8へ変換する。
- 対応形式はRGBA8/BGRA8（UNORM/sRGB）、RGBA16 UNORM/FLOAT。sRGBの追加色変換やHDRトーンマッピングはしない。マルチサンプルは非対応。
- バッファ更新と複製はクリティカルセクションで保護する。UIは別の所有配列とBitmapを使い、映像側からVCLを操作しない。即時D3D11コンテキストはホストの呼び出し規約に従う。
- バッファの識別はObject IDとEffect ID。設定APIとの対応付けはMapRakuと同じレイヤー・開始終了フレームによる検索で、複数候補なら別効果の画像を返さず未取得表示とする。同一オブジェクトへの複数追加は制約あり。
- オブジェクトごとの状態はプラグイン終了まで保持し、終了時にGPU資源・画像・コンテキストを解放する。多数の異なるオブジェクトを扱う製品へ転用する場合は状態回収を検討する。
- ホストAPIへの保存はUTF-8、文字列項目はホスト所有。コールバック外へそのポインターを保持しない。JSON版は1。不正・未知のデータはエラーとして扱い、勝手に上書きしない。
- 終了処理はホストが映像・設定コールバックを終了してから呼ぶ前提。

## 最小手動テスト

1. AviUtl2を終了し、Releaseを `-Install` 付きでビルドする。
2. AviUtl2を起動し、画像や映像を配置したテストプロジェクトへ「SYNC → キャンバステスト」を追加する。
3. 対象フレームを表示し「設定」を押す。編集フォームに取得した背景・キャンバス外枠が表示されること。
4. 左／中央ドラッグで背景と外枠が一緒に移動すること。領域外でボタンを離してもドラッグが終了すること。
5. ホイールでポインター付近の画像位置を保ちながら拡大縮小すること。Fitで全体表示へ戻ること。
6. 入力欄に確認用文字列を入れ、パン・ズームした状態で閉じる。設定データにJSONが記録され、再度開くと復元されること。
7. AviUtl2プロジェクトを保存し、終了・再読込後も設定が復元されること。プレビュー映像は変化しないこと。
8. 別オブジェクト、画像未取得、フレームサイズ変更、100%／150%などのDPIで確認する。

## 確認結果（2026-09-28）

- Delphi 37 Win64 Debug / Release: ビルド成功、警告0・エラー0。
- 自動テスト: 12項目成功。D3D11 WARP画像取得、257px幅でのRowPitch、取得失敗時のクリア、BGRA変換、不正サイズ、効果ごとの分離、曖昧な検索、ズーム中心、JSON復元を確認。
- Release `.auf2`: DLLロード・エクスポート・初期化・SYNC登録・nil映像コールバック・終了のテスト成功。
- Releaseを上記 `SYNC_CanvasTest` フォルダーへ配置済み。
- 実AviUtl2を起動したが応答なしとなり、Computer Useの画面取得も対象画面を正しく取得できなかった。プラグインが原因かは未特定。実ホストへの読み込み、設定ボタン、背景表示、マウス操作、ホストプロジェクト保存・再読込、DPIの目視確認は未完了。
- 自動テストのGPU入力は人工画像であり、実AviUtl2での背景取得を確認したものではない。
- 保管庫はGit管理下ではないため `git diff --check` は実行対象外。
