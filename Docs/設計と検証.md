# グラフプラグインの構成

## 責務と依存方向

`Core` はグラフの構造・装飾・値の解析・目盛・演出計算を持つ。
`Persistence` は構造・装飾のJSONを読み書きする。表題・要素名・単位・値を保存しない。
`Rendering` はCoreを参照し、編集画面と映像出力の双方に同じ透過RGBA画像を返す。
`Editor` は背景キャンバスを継承してグラフ枠と文字の編集を扱う。
`UI` は入力画面とモデルの対応を担当し、`Shell` が画面と処理を接続する。
`Host` はAviUtl2の登録・コールバック・保存を担当する。映像側はVCLを呼ばない。

| フォルダー | 主なユニット |
| --- | --- |
| Core | GraphModel、GraphValues、GraphAnimation |
| Persistence | GraphSettings |
| Rendering | GraphPainter、GraphCartesian、GraphPolar、GraphRenderer、GraphComposite |
| Editor | GraphView、GraphCanvasFrame |
| UI | GraphDataPanel、GraphLayoutPanel、GraphStylePanel、GraphColorPopup |
| Shell | GraphEditorForm |
| Host | GraphPlugin、GraphHostParameters、GraphHostSettings、GraphRenderContext |

独自の汎用ライブラリは新設しない。大きくなった処理は役割ごとに専用ユニットへ分離する。
ファイルの行数だけを目的に処理を分割せず、関連する状態と処理は同じ責務にまとめる。

## 利用する既存部品

- AviUtl2Canvas: ABI、項目登録、オブジェクト・効果別管理、GPU背景取得、パン・ズーム。
- DarkComboBox: グラフ種類・装飾対象の選択。
- ToolbarIcon: 全体表示、編集前に戻す、枠の再配置、文字位置の初期化。
- ColorPicker: 色相・彩度・明度、色コード解析。
- DarkMenu: 値書式のプリセット。
- Delphi同梱System.Skia: 透過、アンチエイリアス、線、文字装飾。Win64のsk4d.dllを隣接配置する。

HorizontalTrackBar、VerticalScrollBar、ShortcutActionは候補としてコピー済みだが現画面では未使用。
文字列・数値表の入力には標準VCLを使用し、専用の汎用表ライブラリは作成しない。

## 保存と編集

- ホストの「表題」「要素名」「単位」「値」が正本。編集開始時に読み込み、×で閉じたときに書き戻す。
- 「設定データ」はversion 2の構造・装飾JSON。旧キャンバス版version 1はグラフ未設定へ移行する。
- 入力が不正な間は理由を画面下に表示し、閉じて採用できない。編集前へ戻すアイコンで開始時点へ復元できる。
- 復元は編集内容を対象とする。パン・ズームは編集表示用で、グラフの出力座標とは別に管理する。
- 文字の補正は標準位置に対する相対座標。構造変更時に既存の装飾・補正を保持する。
- 編集セッション中に縮小した行列は可能な範囲で保持し、再拡大時に戻す。閉じた後はホストへ保存した行列が有効範囲となる。
- 複数項目の書き戻しに失敗した場合は元データの復元を試み、復元にも失敗した場合は明示する。

## 描画と演出

- N角形は行=軸、列=系列。棒・折れ線は行=系列。円は行=区画、列=1。
- 黒背景、灰色の範囲外、影・トンボ、選択枠は編集画面のみ。出力は透過RGBAを入力映像へ合成する。
- ホストコールバック内で背景を取得してからグラフを合成する。ホストポインターを保持しない。
- 描画キャッシュはオブジェクト・効果別。構造・共有値・サイズ・進行・不透明度が変わったときに更新する。
- 登場・退場は時刻から計算。要素進行は1系列または区画につき100。逆方向への変更にも対応する。
- SDKのトラック上限が登録時固定のため「進行」の上限は25600。実系列数×100以降は完成状態を保持する。

## 現在の制約と検討事項

- 要素数は最大64、データ数は最大256。N角形は3要素以上。画像は最大33554432画素。
- 棒・折れ線の凡例3パターン、円の内側・外側・引出線、N角形のラベル距離3パターンを初期案として実装。
- 共通線設定UIはX軸／基準線、Y軸、目盛線、外枠、系列線／棒枠、円区切り線が対象。系列色は系列側の線色を優先する。
- 文字スタイルは表題・要素名・単位・値の4分類。目盛文字は値スタイルを使用する。
- 角度は数値入力。回転ハンドルは未実装。
- 日本語と使用フォントによる文字計測・代替フォント、極端な配置・大量データでの性能は追加確認が必要。
- 背景は編集開始時のスナップショット。保存後に再表示すると更新される。
- 同じ位置の複数対象効果については既存Libの識別制約を継承する。

## 検証方法

1. Win64 DebugとReleaseのプラグインをビルドする。
2. `Tests/run.ps1 -Config Debug` で値・保存・描画・合成、フォーム生成、DLLの公開ABIを検証する。
3. 自動テストのPNGは `Win64/Tests/Debug/graph-1.png` ～ `graph-4.png` に出力する。
4. 実AviUtl2では種類変更、値・色・文字、ドラッグ、復元、保存・再読込、ホスト側推移を確認する。

人工ホストのABIテストは実AviUtl2のUIテストの代わりではない。実施結果はREADMEに分けて記録する。
