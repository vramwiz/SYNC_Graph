# SYNC グラフ

AviUtl2用のグラフフィルター。Delphi 37 / VCL / Win64。
分類は **SYNC**、名称は **グラフ**。

## 実装内容

- N角形、折れ線、棒、積み重ね棒、円。棒・折れ線の縦横切替。
- 構造・配置、文字・値、装飾を右側の縦スクロール領域に並べて編集する。
- 表題・要素名・単位・値はAviUtl2側を正本として読み書きする。
- 値の初期値は0、初期状態はグラフ未設定。値書式の空欄は非表示。
- 自動／手動の目盛、系列ごとの線色・塗色・透明度、折れ線のマーク。
- 4分類のフォント、サイズ、太字・斜体、色、縁取り・影・ぼかし。
- 共通線の線種・太さ・縁取り。系列線と円区切り線にも適用する。
- 枠内の移動・周囲8点のハンドルによるリサイズ、文字の相対位置編集、初期化。
- 枠のドラッグ中は描画済みのグラフ画像を追従表示し、操作終了時に再描画する。
- タイトル・要素名などの文字も優先選択でき、共通の8点ハンドルで個別に移動・拡大縮小する。ドラッグ中は文字画像が追従する。
- 文字選択時は枠下の縁取り・影位置・縁ぼかし・影ぼかしアイコンをドラッグして装飾する。0は無効、影位置は0付近に吸着する。
- 文字選択時だけ上部に文字ツールバーを表示する。Skiaで利用できるフォント、太字・斜体、文字・縁取り・影の色を編集し、右側の装飾群は線・系列の設定に絞る。文字サイズはキャンバス上のハンドルで調整する。
- 参考元の共通ColorPickerPanelを右ペイン下部に配置し、選択中の線色・縁取り色・系列線色・塗色へ反映する。色コードはHEX表示で、HEXとカンマ区切りRGB十進を入力できる。既存のアルファ値は保持する。
- 数値欄では数字にカーソルを重ねたホイール操作でその桁を増減する。右ペインの他の場所では設定を縦スクロールする。
- 編集前へ戻すアイコンと要素名配置のUndoアイコン。フォームの×で採用。入力エラー中は理由を表示する。
- 古い設定で省略された項目は初期値で補完する。設定JSONが壊れていても初期状態の編集画面を開き、理由を表示する。
- 編集背景の透明部分は黒、範囲外は灰色。影とトンボで範囲を表示する。
- グラフは透過RGBAへ描画してホストの入力映像に合成する。編集用の影・トンボ・枠は出力しない。
- 全体の登場・退場フェード、系列／区画ごとの登場とホスト側の進行値による制御。

## ソース構成

`Source/Core`、`Persistence`、`Rendering`、`Editor`、`UI`、`Shell`、`Host`へ責務を分離した。
専用処理は汎用ライブラリ化せず、既存Libを利用する。
詳細は [設計と検証](Docs/設計と検証.md)、[設定画面UI改善仕様](グラフプラグイン_設定画面UI改善仕様.md)、開発ルールは [note.md](note.md)、採用部品は [Lib一覧](Source/Lib/INDEX.md) を参照。

## ビルド・検証

```powershell
.\Source\Lib\AviUtl2Canvas\Tools\build.ps1 -Config Debug
.\Source\Lib\AviUtl2Canvas\Tools\build.ps1 -Config Release
.\Tests\run.ps1 -Config Debug
```

通常ビルドで`C:\ProgramData\aviutl2\Plugin\SYNC_Graph`にauf2と`sk4d.dll`を自動配置する。AviUtl2を終了してからビルドする。

```powershell
.\Source\Lib\AviUtl2Canvas\Tools\build.ps1 -Config Release -Install
```

`-Install`は旧コマンドとの互換引数。使用中のプラグインを上書きできなければビルドエラーになる。

## 操作

1. AviUtl2で「SYNC → グラフ」をフィルターとして追加して設定を開く。
2. 右側の縦並び設定でグラフ種類、要素数、データ数を指定し、行ごとに要素名と値を入力する。
3. 文字を選択して上部の文字ツールバーから書体や色を編集する。線・系列は右側の装飾群で対象と色種を選び、下部の共通カラーピッカーで変更する。
4. 枠内ドラッグで全体移動、周囲8点のハンドルでリサイズ、文字ドラッグで個別位置を調整する。
5. Ctrl+ドラッグまたは中央ドラッグでキャンバス移動、ホイールで拡大縮小する。
6. 値書式欄で右クリックすると書式プリセットを選べる。要素名配置を変更すると個別位置をリセットし、Undoアイコンで直前の配置へ戻せる。
7. ×で閉じると採用する。編集前に戻すアイコンは編集を開いた時点の内容に戻す。

「進行」は1段階100。登録時の固定上限は25600で、実系列数×100以降は完成状態。
背景は編集開始時のスナップショット。同一位置の複数効果の識別には既存Libの制約がある。

## 編集UIの改良（2026-09-29）
Windows Modern Darkを編集フォームと色選択画面に適用。右ペインを460px、表の項目列を220pxへ拡張し、フォント実測に基づく行高・余白を設定した。入力欄・ページタブ・ヘルプの寸法も調整。共通処理は参考元のDarkEditorライブラリへ登録済み。独立フォームの描画画像とモーダル終了を検証し、実AviUtl2での確認はユーザーが行う。

現在の設定画面はページを廃止し、構造・目盛り、行ごとの文字・値、装飾を縦並びにした。要素数・データ数・目盛・相対角度は専用数値欄で編集し、グラフ枠の位置と寸法はキャンバス上の8点ハンドルとドラッグで調整する。相対角度はN角形と円の描画で使用するため残す。線種は描画付きコンボ、線太さ・縁取り太さはスライダーを利用する。共通カラーピッカーは線・系列と文字ツールバーの色対象に接続した。縦スクロール、桁ホイール、行入力のカーソル移動、要素名配置のUndo、色反映はEditorSmokeで検証した。実AviUtl2での操作と異なるDPIでの表示はユーザー確認対象。

設定欄は幅312pxへ縮小し、各入力欄を配置し直した。線種リストの行高と展開幅を指定し、数値欄と線幅スライダーへのホイール操作をEditorSmokeで確認した。Debug/Releaseビルドと配置は成功。実AviUtl2での見た目と操作は未確認。

線種コンボの破線・点線が実線に見える問題を、線分の間隔を明示的に描く方式で修正し、線種名も併記した。Debug/Releaseビルド、既存スモークテスト、配置は成功。数値入力欄のホイール操作は実ホストで動作していないとの報告があり、別途検討する。

数値入力欄を表示用の描画コントロールと編集時のみ表示するTEditに変更した。数字上のホイールは桁単位で増減し、それ以外の位置では設定欄をスクロールする。クリックで全選択編集、Enterで確定、Escで取消、フォーカス喪失で確定する。EditorSmokeではクリック・ホイールのWindowsメッセージ、各編集終了操作を検証した。実AviUtl2での操作は未確認。

位置・寸法の数値欄を削除し、設定の再適用でキャンバス上の枠変更を上書きしないようにした。設定欄の配置・スクロールは `Source/UI/Settings/GraphSettingsPane.pas`、枠の共通計算は `Source/Editor/Geometry/GraphViewBounds.pas`、ドラッグ中の画像キャッシュは `Source/Editor/Preview/GraphViewBitmapCache.pas` に分割した。UIユニットは `Settings` と `Text` に整理した。EditorSmokeで枠値の保持を検証し、96DPIのフォーム画像で上部・下部の配置を確認した。Debug/Releaseビルドと配置に成功。実AviUtl2上の最終操作は未確認。

## ビルド後処理（SYNC_ScreenLayout準拠）

Debug／Releaseともプロジェクト直下にDLLを生成する。標準のビルド前イベントで配置先フォルダーを作成し、ビルド後イベントのcopy /Yでauf2名へのコピーとLib/Skia/Win64/sk4d.dllのコピーを行う。両コピー成功後に元DLLだけを削除する。参照元自体には削除処理はない。

配置先はC:\ProgramData\aviutl2\Plugin\SYNC_Graph。独自の後処理スクリプト、GraphInstall、NoInstall、Win64/Pluginへの二重出力は廃止した。RSM・DCUは保持する。使用中のプラグインへのコピー失敗はビルドエラーとなる。旧Win64/Pluginの過去生成物は未清掃。
